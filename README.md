# 寵物三星／五星計算器

直接開啟：[線上使用工具](http://natsuyuki07321.github.io/aog_pet_calc)

1. 選擇目標「三星」或「五星」。
2. 貼上寵物面板圖片（Ctrl+V），或拖放、選擇圖片。
3. 對照原圖核對八項總值，再按「核對完成，套用總值」。也可直接手動輸入。
4. 填寫寵物目前的等級與強化次數，按預估按鈕。
5. 查看達標等級與區間；切換假設強化次數，可比較強化成功後的素質及預估結果。
6. 在下方查看各個後續等級的總值、白字與綠字。右上角可切換明暗模式。

總值是屬性名稱後、括號前的數字。若圖片含淺藍色加成，請先取消召喚或卸下寵物裝備再截圖。拍照或有浮層的圖片，只要八項屬性未被遮住也可嘗試辨識；拍照會較慢。圖片辨識後請特別核對 0、8、9；等級與強化需手動填寫。

預估結果供參考，仍以遊戲實際面板為準。圖片與計算均在瀏覽器內處理。
